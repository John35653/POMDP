## Required extensions:
- Foundry Toolkit for VS Code
- Azure MCP Server
- GitHub Copilot for Azure
- Github Copilot upgrade 

- These extensions allow for the creation and customization of an agent (our POMDP). 
- This allows us to use predefined tools rather than having to code our own for the agent. 
- This also allows for the use of free agents able to process massive amounts of data without worrying about burning through tokens. 
- You can run the agent(s) inside of VS Code, without the need of the terminal.
- Even though we aren't using the upgrade tool extension, at least at the time of writing, it helps fill out the read tool from the terminal. Will also be useful in case of any need to refactor, but for this pomdp file, most likely not.
